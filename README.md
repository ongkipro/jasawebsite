## 1. Siapa Kami: JasaWebsite.co by ONG (`ongki.pro`)

**JasaWebsite.co by ONG** adalah studio rekayasa perangkat lunak mandiri (*boutique software engineering studio*) dan arsitek sistem digital yang dipimpin oleh **Ongki Herlambang** ([ongki.pro](https://ongki.pro)), berbasis di Surabaya, Indonesia. Kami merancang dan membangun platform web berstandar enterprise untuk perusahaan korporat, brand D2C ritel, distributor nasional, eksportir, dan pelaku bisnis berkembang di Indonesia maupun Asia Tenggara.

### Mengapa Pendekatan Kami Berbeda dari Agensi Biasa?
Di pasar Indonesia, sebagian besar penawaran "jasa bikin web" didominasi oleh agensi template WordPress/Elementor murahan yang lambat, rentan disusupi malware/spam, membebani bisnis dengan biaya sewa server bulanan yang mahal, dan mengunci klien dalam ketergantungan sepihak.

Kami menolak jalan pintas tersebut dan menerapkan standar **pure software engineering**:

1. **Kecepatan Sub-Detik (Sub-0.3s TTFB):** Seluruh website kami dibangun dengan arsitektur modern Static Site Generation (SSG) dan didistribusikan melalui ratusan edge nodes Cloudflare & Vercel global. Pengunjung Anda tidak akan pernah menunggu loading screen.
2. **Berorientasi Konversi Nyata (Bukan Sekadar Brosur Pajangan):** Kami merancang alur halaman untuk memicu aksi komersial nyata: inquiry tender korporat B2B, leads WhatsApp berkualitas dari iklan Meta & Google Ads, atau transaksi belanja instan tanpa potongan komisi marketplace.
3. **100% Hak Milik Kode Sumber (Zero Agency Lock-in):** Seluruh source code, aset, konfigurasi DNS, dan repositori GitHub diserahkan penuh kepada Anda saat serah terima. Anda memiliki kontrol mutlak atas aset digital perusahaan Anda.
4. **$0 Biaya Server Bulanan:** Berkat arsitektur modern edge SSG kami, website Anda dapat beroperasi dengan biaya server **$0/bulan** (bebas biaya sewa hosting tahunan yang menguras kas usaha).
5. **Pelacakan Data & Konversi Presisi:** Setiap tombol dan alur penjualan dilengkapi integrasi Google Tag Manager, Google Analytics 4, dan Server-Side Conversion API (CAPI) untuk Meta Ads & Google Ads yang kebal proteksi privasi browser seluler.

## 6. Tentang Repositori Ini (`ongkipro/jasawebsite`)

Repositori ini menyimpan source code dari platform resmi **JasaWebsite.co by ONG**. Alih-alih membuat website portofolio agensi biasa yang monoton, kami merancang repositori ini sebagai etalase hidup (*living demonstration*) atas standar rekayasa, estetika, dan performa yang kami terapkan untuk klien: **Living Digital Brochure (Buku Lembar-per-Lembar)**.

### Konsep Living Digital Brochure
- **Pengalaman Buku Fisik yang Taktil:** Menghadirkan kembali sensasi membolak-balik lembaran buku portofolio fisik (*two-page spread* di layar desktop dengan bayangan lipatan buku / spine crease, dan *single-sheet swipe* di smartphone dengan gestur jempol `drag="x"`).
- **100% Crawlable & SEO-Friendly (Anti-Canvas Slop):** Berbeda dari flipbook konvensional yang terkunci di dalam Canvas atau PDF viewer tak terindeks, setiap lembaran di platform ini adalah komponen semantic HTML5 (`<article>`, `<h1>`-`<h6>`, `<p>`) yang di-prerender saat build time dengan route canonical tersendiri (`/folio/[slug]`).
- **Dynamic Client-Side SEO Synchronization:** Perpindahan lembaran secara interaktif langsung memperbarui `document.title`, `<meta name="description">`, `<link rel="canonical">`, OpenGraph, Twitter card, dan Schema.org JSON-LD di browser secara real-time via fungsi `syncDocumentSeo(slug)`.
- **Tear-Off Perforated Voucher:** Tombol CTA berwujud kupon sobek taktil dengan jahitan garis putus-putus (*dashed perforation*) dan stempel tinta basah studio ([`InkStamp.tsx`](src/components/ui/InkStamp.tsx)) yang merutekan prospek ke pesan WhatsApp kontekstual sesuai layanan yang sedang dibaca.
- **Warm Swiss Monograph Aesthetic:** Menolak tren visual "AI Card Fatigue" (ratusan kartu berbingkai kotak dengan bayangan berlebihan). Platform ini mengadopsi tipografi monograf Swiss dengan palet kertas hangat (`#fbfbfa`), tinta karbon pekat (`#111111`), pembatas hairline tipis, dan stabilo highlighter.

### Spesifikasi Arsitektur & Tech Stack
- **Framework:** Next.js 16.3.4 (App Router, Turbopack, Static Site Generation / `output: 'export'`)
- **Styling:** Tailwind CSS v4 (Desain berbasis CSS variable native, zero overhead)
- **Animasi Fisik:** Motion 13.2.0 (Framer Motion dengan akselerasi GPU 60–120 FPS, dukungan penuh `prefers-reduced-motion`)
- **Ikonografi:** Lucide React (100% SVG vektor pohon, zero emoji slop)
- **Bahasa & Tipe Data:** TypeScript Strict Mode (Target ES2022)
- **Structured Data:** Master Schema.org JSON-LD Graph (`ProfessionalService`, `FAQPage`, `ItemList`, `BreadcrumbList`)
- **Target Infrastruktur:** Cloudflare Pages / Vercel Edge Singapore (`sin1`) — **$0 Biaya Server Bulanan**

### Panduan Menjalankan Repositori Secara Lokal

Prasyarat: Node.js 20.x atau lebih baru, dan npm.

```bash
# 1. Clone repositori ke mesin lokal
git clone https://github.com/ongkipro/jasawebsite.git
cd jasawebsite

# 2. Pasang seluruh dependensi
npm install

# 3. Jalankan development server lokal
npm run dev
# Buka http://localhost:3000 pada peramban Anda

# 4. Kompilasi build statis (Static Site Generation / SSG)
npm run build
# Seluruh output statis dikompilasi ke direktori /out (41 halaman HTML/XML)

# 5. Jalankan automated smoke verification suite
npm test
# Menjalankan 72 checks deterministik: JSON-LD, routes, SEO titles, no-pipe, no-slop

# 6. Audit kualitas dan linting kode
npm run lint
```
